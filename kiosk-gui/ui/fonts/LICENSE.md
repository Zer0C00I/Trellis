# Bundled fonts

The kiosk runs offline, so its fonts ship with it. Both are released under the
SIL Open Font License 1.1 (https://openfontlicense.org).

- `Onest-Regular.ttf`, `Onest-SemiBold.ttf`: Onest. Copyright 2021 The Onest
  Project Authors (https://github.com/simpals/onest). Static 400 and 600
  instances of the variable font, Latin and Cyrillic subsets merged.
- `JetBrainsMono-Bold.ttf`: JetBrains Mono. Copyright 2020 The JetBrains Mono
  Project Authors (https://github.com/JetBrains/JetBrainsMono). Static 700
  instance, Latin subset, used for the pairing code.
