# Bundled fonts

The family app runs offline, so its fonts ship with it. Both are released
under the SIL Open Font License 1.1 (https://openfontlicense.org).

- `onest-*.woff2`: Onest. Copyright 2021 The Onest Project Authors
  (https://github.com/simpals/onest).
- `jetbrains-mono-*.woff2`: JetBrains Mono. Copyright 2020 The JetBrains Mono
  Project Authors (https://github.com/JetBrains/JetBrainsMono).

These are the Latin and Cyrillic subsets of the variable fonts, as served by
Google Fonts.
