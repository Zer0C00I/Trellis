# Automated Jury Demo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One command builds `demo/out/demo.mp4`: a silent 1920x1080 walkthrough of the kiosk (left) and the family app (right) in English, with a simulated pairing, for the hackathon jury.

**Architecture:** A scenario file lists scenes (kiosk screen, app steps, caption, seconds). The kiosk side is rendered without a window by the existing `examples/screens.rs` (Slint `take_snapshot`). The app side is the real UI in its mock backend, driven in headless Chromium over the DevTools protocol (the same technique as `family-app/ui/tools/smoke.mjs`), one continuous session so mock state carries from scene to scene. Each scene is composed into one frame by a small HTML page screenshotted by Chromium (no `drawtext`, real fonts), and `ffmpeg` joins the frames into the video. Nothing in the video is live: pairing and the withdrawal are scripted, and the video says so.

**Tech Stack:** Node (no packages), headless Chromium, `ffmpeg`, `cargo run --example screens`.

**Spec:** none written (design agreed in chat on 2026-10-12): kiosk and app together, kiosk as Slint frames without a window, English, simulated pairing, silent video.

## Global Constraints

- **Language:** English only: kiosk `en`, app `?lang=en`.
- **Honesty:** every scene carries a caption; the pairing and approval scenes say `simulated`. No real Bluetooth or chain is used.
- **No new dependencies:** Node core modules only; `Cargo.lock` stays untouched. `ffmpeg` and `chromium` must be on `PATH` (`CHROMIUM=/path` overrides).
- **Product code stays product code:** only two small, optional additions: `screens.rs` takes `name=`/`amount=` arguments; `mock-api.js` takes `?persona=en` (English names). Defaults and all existing tests are unchanged.
- **Output** goes to `demo/out/` which is git-ignored. Total length 60 to 120 seconds.
- **Commits:** on the current branch, no attribution lines, never `git add` anything under `target/`, `node_modules/` or `demo/out/`.

## File Structure

| File | Responsibility |
|---|---|
| `kiosk-gui/examples/screens.rs` | accepts `name=<text>` and `amount=<text>` so the kiosk can show the same person and sum as the app |
| `family-app/ui/mock-api.js` | `?persona=en` swaps the two Russian demo names for English ones |
| `demo/scenario.mjs` | the scenes: data only |

| `demo/test/scenario.test.mjs` | the scenario is valid: screens exist, keys exist in the catalog, length is in range |

- [ ] **Step 2: The browser driver**

`demo/cdp.mjs`:

```js
// Minimal headless-Chromium driver over the DevTools protocol, no packages.
import { spawn } from 'node:child_process';
import { createServer } from 'node:http';
import { readFile, mkdtemp, rm, writeFile } from 'node:fs/promises';
import { tmpdir } from 'node:os';
import { extname, join, normalize } from 'node:path';

const TYPES = { '.html': 'text/html', '.js': 'text/javascript', '.mjs': 'text/javascript', '.css': 'text/css', '.png': 'image/png' };

export async function serve(root) {
  const server = createServer(async (req, res) => {
    const path = normalize(new URL(req.url, 'http://x').pathname).replace(/^(\.\.[/\\])+/, '');
    try {
      const body = await readFile(join(root, path === '/' ? 'index.html' : path));
      res.writeHead(200, { 'content-type': TYPES[extname(path)] ?? 'application/octet-stream' }).end(body);
    } catch {
      res.writeHead(404).end();
    }
  });
  await new Promise((r) => server.listen(0, '127.0.0.1', r));
  return { url: `http://127.0.0.1:${server.address().port}`, close: () => server.close() };
}

export async function launch({ width, height, scale = 1 }) {
  const profile = await mkdtemp(join(tmpdir(), 'demo-'));
  const chrome = spawn(process.env.CHROMIUM || 'chromium', [
    '--headless=new', '--no-sandbox', '--disable-gpu', '--hide-scrollbars', '--remote-debugging-port=0',
    `--user-data-dir=${profile}`, 'about:blank',
  ], { stdio: 'ignore' });
  const died = new Promise((_, reject) => {
    chrome.once('error', (e) => reject(new Error(`cannot start Chromium: ${e.message}`)));
    chrome.once('exit', (code) => reject(new Error(`Chromium exited during startup (code ${code})`)));
  });
  died.catch(() => {});

  async function endpoint() {
    for (let i = 0; i < 300; i++) {
      try {
        const port = (await readFile(join(profile, 'DevToolsActivePort'), 'utf8')).split('\n')[0].trim();
        const page = (await (await fetch(`http://127.0.0.1:${port}/json`)).json()).find((t) => t.type === 'page');
        if (page) return page.webSocketDebuggerUrl;
      } catch { /* not up yet */ }
      await new Promise((r) => setTimeout(r, 100));
    }
    throw new Error('Chromium did not start within 30 s');
  }

  const ws = new WebSocket(await Promise.race([endpoint(), died]));
  await new Promise((r, j) => { ws.onopen = r; ws.onerror = () => j(new Error('DevTools socket failed')); });
  let id = 0;
  const pending = new Map();
  const loaders = [];
  ws.onmessage = ({ data }) => {
    const m = JSON.parse(data);
    if (m.id && pending.has(m.id)) pending.get(m.id)(m);
    if (m.method === 'Page.loadEventFired') loaders.splice(0).forEach((r) => r());
  };
  const send = (method, params = {}) => new Promise((r) => { pending.set(++id, r); ws.send(JSON.stringify({ id, method, params })); });
  await send('Page.enable');
  await send('Runtime.enable');
  await send('Emulation.setDeviceMetricsOverride', { width, height, deviceScaleFactor: scale, mobile: false });

  const evaluate = async (expression) => {
    const r = await send('Runtime.evaluate', { expression, awaitPromise: true, returnByValue: true });
    if (r.result.exceptionDetails) throw new Error(r.result.exceptionDetails.exception?.description ?? 'evaluate failed');
    return r.result.result.value;
  };
  const sleep = (ms) => new Promise((r) => setTimeout(r, ms));
  async function until(expression, what, ms = 30000) {
    const end = Date.now() + ms;
    while (Date.now() < end) {
      if (await evaluate(expression)) return;
      await sleep(100);
    }
    throw new Error(`timed out waiting for: ${what}\npage text: ${await evaluate('document.body.innerText')}`);
  }
  const navigate = (url) => new Promise((resolve, reject) => {
    const timer = setTimeout(() => reject(new Error(`no load event for ${url}`)), 15000);
    loaders.push(() => { clearTimeout(timer); resolve(); });
    send('Page.navigate', { url });
  });
  const click = (label) => until(
    `(() => { const e = [...document.querySelectorAll('button,a')].find(e => e.textContent.trim() === ${JSON.stringify(label)}); if (!e) return false; e.click(); return true; })()`,
    `a button or link "${label}"`);
  const fill = (selector, value) => evaluate(
    `(() => { const e = document.querySelector(${JSON.stringify(selector)}); e.focus(); e.value = ${JSON.stringify(value)}; e.dispatchEvent(new Event('input', {bubbles:true})); })()`);
  const screenshot = async (path) => {
    const r = await send('Page.captureScreenshot', { format: 'png' });
    await writeFile(path, Buffer.from(r.result.data, 'base64'));
  };
  const close = async () => {
    ws.close();
    chrome.kill();
    await rm(profile, { recursive: true, force: true }).catch(() => {});
  };
  return { evaluate, until, navigate, click, fill, screenshot, sleep, close };
}
```

import { mkdirSync } from 'node:fs';
import { scenes, APP_URL } from './scenario.mjs';
import { launch, serve } from './cdp.mjs';
import { setLocale, t } from '../family-app/ui/i18n.js';

setLocale('en', { persist: false });
mkdirSync('demo/out/app', { recursive: true });
const server = await serve('family-app/ui');
const page = await launch({ width: 390, height: 780 });
try {
  await page.navigate(`${server.url}/index.html${APP_URL}`);
  await page.until("document.getElementById('app').innerText.length > 20", 'the app to render');
  for (const s of scenes) {
    for (const step of s.app) {
      if (step.do === 'fill') await page.fill(step.selector, step.value);
      else if (step.do === 'click') await page.click(t(step.key));
      else if (step.do === 'wait') await page.until(`document.body.innerText.includes(${JSON.stringify(t(step.key))})`, t(step.key), 60000);
      else if (step.do === 'pause') await page.sleep(step.ms);
    }
    await page.sleep(400);
    await page.screenshot(`demo/out/app/${s.id}.png`);
    console.log('app', s.id);
  }
} finally {
  await page.close();

```js
import { execFileSync } from 'node:child_process';
import { existsSync, mkdirSync, writeFileSync } from 'node:fs';
import { scenes } from './scenario.mjs';
import { launch, serve } from './cdp.mjs';

mkdirSync('demo/out/frames', { recursive: true });
writeFileSync('demo/out/compose.html', `<!doctype html><meta charset="utf-8">
<style>
  html,body{margin:0;width:1920px;height:1080px;background:#0f1419;color:#fff;font-family:system-ui,sans-serif}
  .stage{position:absolute;inset:0 0 170px 0;display:flex;gap:80px;align-items:center;justify-content:center}
  .label{font-size:26px;opacity:.7;margin-bottom:14px;text-align:center}
  .kiosk img{width:1040px;height:624px;border:6px solid #fff;border-radius:18px;display:block;background:#fff}
  .phone img{width:390px;height:780px;border:6px solid #fff;border-radius:34px;display:block;background:#fff}
  .caption{position:absolute;left:0;right:0;bottom:0;height:170px;display:flex;align-items:center;justify-content:center;
    padding:0 120px;font-size:40px;line-height:1.3;text-align:center;background:#000}
</style>
<div class="stage" id="stage"></div><div class="caption" id="caption"></div>
<script>
  const p = new URLSearchParams(location.search);
  const part = (cls, label, src) => src ? '<div class="' + cls + '"><div class="label">' + label + '</div><img src="' + src + '"></div>' : '';
  document.getElementById('stage').innerHTML = part('kiosk', 'Kiosk', p.get('kiosk')) + part('phone', 'Family app', p.get('app'));
  document.getElementById('caption').textContent = p.get('caption');
  Promise.all([...document.images].map((i) => i.decode().catch(() => {}))).then(() => { document.title = 'ready'; });
</script>`);

const server = await serve('demo/out');
const page = await launch({ width: 1920, height: 1080 });
try {
  for (const s of scenes) {
    const q = new URLSearchParams({ caption: s.caption });
    if (s.kiosk) q.set('kiosk', `kiosk/${s.id}.png`);
    if (existsSync(`demo/out/app/${s.id}.png`)) q.set('app', `app/${s.id}.png`);
    await page.navigate(`${server.url}/compose.html?${q}`);
    await page.until("document.title === 'ready'", `frame ${s.id}`, 15000);
    await page.screenshot(`demo/out/frames/${s.id}.png`);
  }
} finally {
  await page.close();
  server.close();
}

const list = scenes.map((s) => `file 'frames/${s.id}.png'\nduration ${s.seconds}`).join('\n');
writeFileSync('demo/out/frames.txt', `${list}\nfile 'frames/${scenes.at(-1).id}.png'\n`);
execFileSync('ffmpeg', ['-loglevel', 'error', '-y', '-f', 'concat', '-i', 'demo/out/frames.txt',
  '-vf', 'fps=30,format=yuv420p', '-c:v', 'libx264', 'demo/out/demo.mp4'], { stdio: 'inherit' });
console.log('demo/out/demo.mp4');
```
